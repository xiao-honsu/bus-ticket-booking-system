## Our Commitment to Accessibility

At BusTicket, we are committed to ensuring digital accessibility for all users, including people with disabilities. We strive to meet or exceed the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards.

## Accessibility Features

### 1. Keyboard Navigation

Our platform is fully navigable using keyboard only:

**Essential Shortcuts**:

- `Tab` - Move to next interactive element
- `Shift + Tab` - Move to previous element
- `Enter` or `Space` - Activate buttons and links
- `Esc` - Close modals and dialogs
- `Arrow keys` - Navigate menus and lists

**Skip Links**:

- "Skip to main content" link at page top
- Bypass navigation and go directly to content
- Hidden visually but available to screen readers

**Focus Indicators**:

- Clear visual focus on all interactive elements
- High contrast focus rings
- Focus trap in modals and dialogs
- Logical tab order throughout

### 2. Screen Reader Support

We ensure compatibility with major screen readers:

**Supported Screen Readers**:

- JAWS (Windows)
- NVDA (Windows)
- VoiceOver (macOS, iOS)
- TalkBack (Android)

**Screen Reader Features**:

- Semantic HTML structure
- ARIA labels and descriptions
- Landmark regions (header, nav, main, footer)
- Live regions for dynamic content
- Alternative text for all images
- Form labels and error announcements

**Dynamic Content Announcements**:

- Real-time seat availability updates
- Booking status changes
- Form validation errors
- Success confirmations
- Loading states

### 3. Visual Design

**Color & Contrast**:

- WCAG AA compliant color contrast ratios
- Minimum 4.5:1 for normal text
- Minimum 3:1 for large text
- Information not conveyed by color alone
- Icons paired with text labels

**Text Readability**:

- Resizable text up to 200% without loss of functionality
- Clear, readable fonts (system fonts)
- Sufficient line height (1.5)
- Adequate letter spacing
- No text embedded in images (where possible)

**Responsive Design**:

- Mobile-friendly interface
- Touch targets minimum 44x44 pixels
- Zoom up to 400% without horizontal scrolling
- Flexible layouts adapt to screen size

### 4. Forms & Input

**Form Accessibility**:

- All fields have associated labels
- Required fields clearly marked
- Error messages are descriptive and actionable
- Success confirmations announced
- Autocomplete attributes for common fields

**Input Assistance**:

- Placeholder text as hints (not labels)
- Format examples provided
- Real-time validation feedback
- Clear error messages
- Instructions before form fields

**Interactive Elements**:

- Large, easy-to-click buttons
- Touch-friendly controls on mobile
- Disabled states clearly indicated
- Loading states announced

### 5. Multimedia Content

**Images**:

- Descriptive alt text for all informative images
- Decorative images marked as such (alt="")
- Complex images have long descriptions
- SVG graphics include titles and descriptions

**Videos** (when available):

- Captions for all videos
- Transcripts provided
- Audio descriptions (when applicable)
- Pause, stop, and volume controls

**Audio**:

- Transcripts for audio content
- Volume controls accessible
- Background audio can be paused

### 6. Interactive Features

**Seat Selection**:

- Keyboard-navigable seat map
- Screen reader announces seat status
- Clear indication of selected seats
- Alternative list view available
- Seat type and price announced

**Real-Time Updates**:

- Polite ARIA live regions for non-critical updates
- Assertive announcements for important changes
- Status changes clearly communicated
- Visual and programmatic updates synchronized

**Modals & Dialogs**:

- Focus trapped within modal
- Esc key closes modal
- Focus returns to trigger element on close
- Screen reader announces modal content
- Clear heading hierarchy

### 7. Navigation

**Site Navigation**:

- Consistent navigation across pages
- Clear, descriptive link text
- Breadcrumb trails where applicable
- Logical heading structure (H1, H2, H3)
- Search functionality available

**Landmarks**:

- Semantic HTML5 elements
- ARIA landmarks for regions
- Main navigation labeled
- Content regions clearly defined
- Footer information accessible

**Menus**:

- Dropdown menus keyboard accessible
- Submenus announced to screen readers
- Current page indicated
- Menu state changes announced

## Known Limitations

We are continuously working to improve accessibility. Current known limitations:

1. **Seat Map Visualization**: While keyboard accessible, visual representation may not convey all information to screen reader users. Alternative list view available.

2. **Real-Time Updates**: Some rapid real-time changes may overwhelm screen readers. We use debouncing and polite announcements to minimize this.

3. **Third-Party Content**: Payment gateways and OAuth providers have their own accessibility standards. We've chosen the most accessible options available.

4. **PDF Documents**: Some downloadable content may not be fully accessible. Contact us for alternative formats.
